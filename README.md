# Personal Finance Tracker

A Java-based personal finance tracker that uses SQLite for data storage and Python for data analysis and visualization.

## Features

- Add, view, edit, and delete expenses
- Organize expenses by spending category
- Set and track a budget
- Calculate total spending, remaining budget, and budget usage
- Identify largest and average expenses
- Store expense data in a SQLite database
- Export expense data to CSV
- Analyze spending patterns using Python and pandas
- Visualize spending by category and over time

## Technologies

- Java
- SQLite
- SQL
- JDBC
- Python
- pandas
- Matplotlib
- Git/GitHub

## Project Structure

- `Main.java` — Handles the application menu and user interaction
- `Expense.java` — Represents an individual expense
- `ExpenseManager.java` — Manages expenses, budgets, and database operations
- `ExpenseType.java` — Defines expense categories
- `analysis.py` — Performs data analysis and creates visualizations
